# WAVE Demo Implementation Plan

**Goal:** 在既有無障礙元件教學站新增 `/test-demo/`，提供已確認的九個 WAVE 範例。

**Architecture:** 使用既有 Container、PageHeader、Card、Tag、Input、Field、Button、SearchIcon、Table、Link，組成志工活動報名頁。學員頁不提供規則 ID 或解答；WAVE 對照與驗證步驟寫在 README。沿用 root layout、設計 tokens 與 appPath，支援靜態匯出與 GitHub Pages。

**Tech Stack:** Next.js 16 App Router、React 19、Tailwind CSS 4、Vitest、Testing Library。

## Nine agreed examples

| WAVE category | Item | Placement |
| --- | --- | --- |
| Errors | alt_missing | 活動海報，普通 img 缺 alt |
| Errors | label_missing | 姓名文字與 Input 無程式關聯 |
| Errors | button_empty | 查詢名額 Button 僅包含隱藏於無障礙樹的 SearchIcon |
| Contrast Errors | contrast | 白底的淺灰色小字 |
| Alerts | heading_skipped | 參加資訊 h2 之後直接使用報名資格 h4 |
| Alerts | table_layout | 活動時段表的標題列刻意使用 td |
| Features | alt_null | 不傳達資訊的裝飾圖 alt="" |
| Structural Elements | h1 | PageHeader 的活動名稱 |
| ARIA | aria_label | SearchIcon Button 的 aria-label="搜尋活動" |

這是九個目標範例，不是九個 WAVE 圖示的保證。站內共用導覽、頁尾與標題也會產生正常的 WAVE 資訊。正式 Chrome WAVE 檢查需與 DOM、CSS 驗證分開記錄。
